# Info:

A simple python script that shows you stats about your GitHub profile.

# Requirements:

1. Python 3.10, 3.11 or 3.12 (older or newer versions may be supported, but these three are 100% surely working)
2. The "requests" Python library (included in the requierments.txt, so you just need to follow the steps down at "Usage".)

# Usage:

1. Clone the repo using the command ``` git clone https://github.com/VloStudios/checkyaprofile ```

2. ``` cd ``` into the directory with ``` cd checkyaprofile ```

3. Do ``` pip install -r requirements.txt ```

4. Do ``` python main.py ```
